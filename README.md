PREGUNTAS TALLER 1:

1.  ¿Cuál es la diferencia entre la clase CuentaBancaria y un objeto CuentaBancaria?
    - CuentaBancaria es el molde o plantilla en el cuál me basaré para crar los objetos y un objeto CuentaBancaria es el propio objeto ya creado a partir de la plantilla.
2. ¿Qué hace exactamente la palabra new?
     - La palabra new es usada para crear un nuevo objeto a partir de una clase (plantilla o molde).
3. Si tienes dos cuentas a y b y ejecutas a.consignar(1000), ¿cambia el saldo de b? Justifica tu respuesta.
     - No cambia el saldo de b, porque cuando se ejecuta: "a.consignar(1000)" Se está especificando mediante "a." que la consignación va para la cuenta u objeto "a".
4. ¿Por qué se dice que el método retirar protege el estado del objeto?
     - El método retirar protege el estado del objeto porque no permite la modificación del atributo Saldo, sino que verifica la regla del negocio.
